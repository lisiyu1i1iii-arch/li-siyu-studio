# LI SIYU — MY LITTLE STUDIO
# PET INTERACTION SYSTEM SKILL

## 用途

规范 LI SIYU — MY LITTLE STUDIO 中猫和狗的点击、拖拽、动画、音效和空间行为。

## 核心设计

> 「点击是互动，拖拽是改变位置。」

---

## 1. 通用交互原则

猫和狗都支持：

### A. Click

- 真正点击才触发互动。
- pointer down → move → up 位移小于约 5~8px 才认定为 click。
- drag 期间绝对不能触发 click。
- 不触发 Focus / Overlay / 相机变化。

### B. Drag

- 按住猫/狗并移动即可拖拽。
- 超过点击阈值后进入 drag。
- 沿房间地面移动。
- 不允许进入墙体、房间外或明显家具内部。
- 拖拽不改变相机。
- 松开后停留在新位置。
- 移动端触摸同样遵循 click / drag 区分。

---

## 2. 猫

猫保持：

- Abyssinian
- 左沙发上的原始位置只是默认位置。
- 呼吸 idle 永久保留。

### Click

播放：

`猫叫.wav`

然后：

坐起 → 打哈欠 → 回到蜷缩状态。

### Drag

- 可以把猫移动到房间其他安全地面位置。
- 拖拽结束后继续呼吸 idle。
- 点击新位置的猫仍然可以正常触发猫互动。
- 不因为位置改变而改变猫的动画逻辑。

---

## 3. 狗

狗保持：

- Pembroke Welsh Corgi
- 原有黄色 / 白色外观
- 原有四足奔跑动画。

### 默认位置

点击狗后执行原有「逆时针绕中央地毯一圈」互动。

### 但如果狗被拖拽到新位置

不要强制狗瞬移回中央地毯。

改为：

> **Local Run**

点击狗后：

1. 记录点击前狗的当前位置 P。
2. 以 P 为中心生成一条安全的小型巡回路线。
3. 狗从 P 出发奔跑。
4. 根据周围空间动态决定路线大小。
5. 空旷区域可以跑较大的弧线 / 小圈。
6. 靠近墙壁、沙发、桌子等障碍物时自动缩小路线或改为折返路线。
7. 路线过程中不得穿透家具、墙壁、地毯以外的禁止区域或其他宠物。
8. 完成约一圈巡回后回到 P。
9. 最终位置必须恢复到点击前的位置。
10. 跑步结束后恢复 idle。

因此：

- 默认狗：点击 → 逆时针绕中央地毯一圈 → 回到原位。
- 被拖走后：点击 → 从当前位置开始局部巡回 → 回到当前位置。

不要出现：

> 拖到新位置 → 点击 → 瞬移回地毯 → 跑步。

---

## 4. 狗的空间路线

优先使用「当前位置附近安全路线」。

路线优先级：

1. 小型圆弧 / 环绕
2. 椭圆路线
3. 遇到障碍物时使用折返路线

路线必须：

- 在地面平面计算。
- 保持合理运动半径。
- 自动限制在房间边界。
- 尽量避开家具。
- 避免猫。
- 避免机器人吸尘器。
- 避免穿过墙体。
- 不改变 Y 高度。

不要为了实现路线而引入复杂物理引擎。

---

## 5. 音频

### BGM

`public/assets/audio/网站BGM.mp3`

- 点击 ENTER 成功进入小屋后播放。
- 循环。
- 默认音量约 0.25。
- 全局只允许一个 BGM 实例。
- 首页不播放。
- 浏览器拒绝播放时不能导致页面错误。

### 猫

`public/assets/audio/猫叫.wav`

- 每次真实 click 播放一次。
- 不循环。
- 拖拽不播放。

### 狗

`public/assets/audio/狗叫.wav`

- 每次真实 click 播放一次。
- 不循环。
- 拖拽不播放。

不要恢复：

- `src/lib/key-sound.ts`
- `public/assets/audio/key-press.wav`

Guestbook 键盘音效保持删除。

---

## 6. 动画原则

### 拖拽

- 物体平滑跟随鼠标 / 触摸。
- 不产生突然跳跃。
- 保持地面高度。
- 松手后保持最终位置。

### 狗跑步

- 真正四足奔跑。
- 身体朝向运动方向。
- 转弯时平滑旋转。
- 不瞬移。
- 跑完平滑回到 P。

### 猫

- 拖拽后仍然保留呼吸 idle。
- 点击后的坐起、打哈欠、回蜷缩必须保持。

## 8. 质量标准

必须保证：

> Click ≠ Drag

- 拖拽结束不能误触发点击。

狗被拖到新位置后：

> 点击狗 → 从新位置开始活动 → 回到新位置。

猫被拖到新位置后：

> 点击猫 → 正常猫互动 → 留在新位置。

不能出现：

- 狗瞬移
- 猫瞬移
- 狗跑到家具里面
- 狗穿墙
- 猫被拖到空中
- 拖拽触发叫声
- 拖拽触发跑步
- 相机跟着宠物移动
- 多个 BGM 同时播放

---

## 9. 验证

完成实现后运行：

```
npm run typecheck
npm run lint
npm run build
```

然后手动验证：

1. 默认位置点击猫
2. 拖猫到新位置，再点击猫
3. 默认位置点击狗
4. 拖狗到房间空旷位置，再点击狗
5. 拖狗到家具附近，再点击狗
6. 拖动猫狗时确认不会触发 click
7. ENTER 后确认 BGM 播放且只播放一次
8. 猫 click 播放猫叫
9. 狗 click 播放狗叫
10. Guestbook 键盘音效仍然不存在

如果发现现有功能与本 Skill 冲突：

> 优先保留现有稳定功能，只局部重构冲突部分。
